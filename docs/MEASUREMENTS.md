# 실측 원장

> 이 프로젝트가 숫자로 말할 수 있는 것 전부. 각 행에 **커밋·날짜·모델·설정**을 붙인다.
> 산출물 원본은 `docs/results/`(gitignore 된 reports/ 대신 보존한 사본). 채점기는 `scripts/score.py`.
>
> ⚠️ **읽기 전에**: q2는 승격기·채점기·truth가 같은 날 함께 진화한 **개발 케이스**다(훈련=시험). truth는

> 무혐의 케이스가 없어 오경보율은 측정 불가. 아래 수치는 이 한계 안에서만 유효하다(docs/REVIEW-2026-09.md §측정).

## 5. 채점기 자체의 한계 (숫자를 믿기 전에)

- 도메인 suffix 매칭이 양방향 — `found={'com'}`으로 domR 1.0 가능(실측). 단방향으로 고쳐야 함.
- truth의 c2 버킷에 인바운드 공격자 5개가 들어 있음(truth 본문 스스로 "전건 시도 실패") — attacker 버킷 부재의 흔적.
- AGG는 케이스 매크로 평균, 열마다 분모가 다른데 n 미표시. `pipeline_status≠ok`가 0점과 구분 안 됨.
- 보고서/truth에 git sha·evidence sha·model·think 스탬프 없음 → 이 문서가 그 역할을 임시로 한다.
